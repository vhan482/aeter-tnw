# Aeternum TNW — Guild Operations Tracker

A low-cost, planned guild management and analytics platform for **Ragnarok: The New World**.

**Project state: specification only — application development and VPS deployment have not begun.**

Read [`NORTH_STAR.md`](NORTH_STAR.md) for product scope, business rules, planned architecture and open questions.

AI coding agents: start with [`AGENTS.md`](AGENTS.md) and [`AI/README.md`](AI/README.md).

Planned modules: weekly member/GR snapshots; Mirror World damage; Guild League Main/Sub combat-support-strategy; Guild Siege; before/during/after attendance; Member Action Center; reviewed screenshot extraction and Google Drive/Sheets reporting.

Planned stack: React, TypeScript, Express, PostgreSQL, Google Drive/Sheets APIs, optional local OCR. VPS co-hosting with Zulip only after resource/health verification.
